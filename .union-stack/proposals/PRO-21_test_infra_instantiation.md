# [PRO-21] 테스트 인프라의 이행 — 새 구조 0, 선언≠이행 공백 3개

## 1. 배경 — 격자는 이미 선언했다 (DESIGN_RATIONALE §5.2 3분할)

| 층 | 거처 | 선언 | 실태 (2026-08-27 실측) |
|---|---|---|---|
| 전략 | `architecture` | 규정됨 | 더미(ARCH-01) — 상류 실전략 미기록 |
| 도구 (호출 규약) | `[CON-00]` 카탈로그 | 셀·`consumers:` 배선까지 존재 | **전부 가공 예시, 실자산 0** |
| 케이스 (통과 조건) | `FLOW-*` 옆 (층 3) | 체크박스 형식 존재 | 어떤 게이트도 안 읽음 |

증거 수신(`verification/raw/evidence.md` ← CI append)은 작동한다. 공백은 셀이 아니라 **내용물·동기화·계기판**이다.

## 2. 실측된 공백 셋 — 전부 기존 병리의 재현

- **자기 사용 0 ([LSN-17] 문법)**: 상류의 실인프라 — 37개 `scripts/*.test.js`, `check()` 카운터 관용구,
  순수함수 export 규약, `node` 직접 실행, `fs_walk.copyTree`·`dataShape()` 공유 픽스처 — 가
  평면 어디에도 없고 파일 머리 주석에만 산다. 셀은 배송하면서 자기는 안 쓴다.
- **동기화 무수단 (선언≠배송, [ADR-18] 자리)**: §5.6이 "자동 추출 권장"을 선언했으나 스크립트가 없다.
  §5.6 자신의 경고: *낡은 카탈로그는 중복을 유발한다*.
- **무관측**: `health.js` 14개 차원에 테스트 차원이 없다. 재사용 규칙(AGENTS.md 규칙 4)은 있는데
  계기판이 없다 — §5.5 실측("문제는 의지가 아니라 가시성")이 예언한 그 공백.

## 3. 채택안 — 기존 문법 3벌 재사용

1. **도그푸딩 (본 제안과 함께 이행됨 — [ADR-51])**: `[CON-00]`을 상류 실관용구로 채운다
   (필수 3요소: 존재·경로·호출법). Schema 편집은 인간 채팅 승인(`Approved-by:`), 누설 게이트는
   [LSN-17]과 같은 근거(위탁 데이터 0, 더미化하면 카탈로그이길 그만둠)로 METHODOLOGY 등재.
2. **자동 추출 생성 뷰**: `scripts/test-catalog.js` — 테스트 파일·헬퍼의 머리 주석에서 3요소를
   추출해 CON-00 마커 블록에 컴파일. `tools-index`·`blocks-index`와 같은 문법
   (코드가 진실 · 카탈로그는 투영 · 드리프트는 CLARIFY · 로직 1벌 [ADR-44]).
3. **`health.js`에 `test infra` INFO 차원**: 카탈로그 실자산 수 · 테스트 파일 수 ·
   FLOW 층 3 케이스 수 · evidence 최신성. **게이트 아닌 INFO** — §5.5가 하드 게이트를 기각했다.

## 4. 분할원리 점검 ([PRO-04])

(a) 테스트 인프라 없는 시스템은 없다 ✓ · (b) 기존 칸에 들어간다 ✓ — 전략=ARCH · 도구=CON ·
케이스=FLOW 옆 · 증거=EVD, 전부 기배정. **새 기둥·도메인·티어 0** — 내용물 채움 + 생성 뷰 + 관측.

## 5. 하지 않는 것 (경계)

- ⛔ `TEST` 도메인 신설 — (b) 불충족, [ADR-48]과 같은 판정.
- ⛔ 재사용 하드 게이트(커밋 전 조회 증명) — §5.5 실측 기각. 가시성으로 푼다.
- ⛔ 수기 카탈로그 유지 — §5.6 자기 경고. 2단계 승인 전까지 1단계 내용은 수기지만, 드리프트는
  2단계가 닫는다(1단계는 씨앗이지 정착이 아니다).
- ⛔ 층 3 ↔ EVD 자동 배선 — 지금은 관측만. 재개 조건: 층 3 체크박스와 실테스트의 불일치가
  실제 사고로 2~3회 관측될 때.

## 6. 미결 (인간 판단)

- `init`의 CON-00 처리: 현행 `EXPLICIT_DUMMIES`(삭제) 유지 vs `RESET_TARGETS`(스켈레톤 리셋)로
  이동 — 어답터가 빈 셀 대신 형식 있는 빈 카탈로그로 시작하게 할지. 본 제안은 현행 유지로 두고
  변경은 승인 시 별도 이행한다.
- 전략 층(ARCH) 실기록 — 상류의 "순수 로직/IO 분리 → FS 비의존 테스트" 규범 명문화. 규범 문서는
  GRANT 스코프 밖이라 별도 승인 필요.

## 7. 판정 기준

- 2단계: 실제 신규 테스트 헬퍼를 카탈로그 없이 추가했을 때 드리프트 CLARIFY 가 무는가
  (가드를 먼저 물리는 [ADR-40] 절차로 검증).
- 3단계: 어답터 형상(팔)에서도 차원이 크래시 없이 INFO 를 낸다.
