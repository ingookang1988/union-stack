## 0. 판정 기준 — 두 시스템은 같은 층이 아니다

대상 문서는 **런타임 하네스** 아키텍처다(에이전트를 실행·도구 호출을 중개·상태를 보유·샌드박스를 소유).
union-stack은 **문서 통제 평면**이다(실행 루프는 Claude Code 등 플랫폼이 소유).
따라서 "8칸 중 3칸 = 37% 완성"으로 읽으면 틀린다. 셀 판정을 5값으로 둔다.

| 값 | 뜻 |
|---|---|
| 있음 | 실물이 있고 게이트로 강제됨 |
| 부분 | 대응물은 있으나 문서의 계약보다 약함 |
| 비범위 | 실행 런타임을 소유해야만 가능 — union-stack의 결함이 아님 |
| 선택 안 함 | 측정 후 명시적으로 기각(ADR 근거 있음) — 공백이 아님 |
| 공백 | 범위 안 · 미기각 · 실제로 비어 있음 |

## 2. 반대 방향 — union-stack이 앞선 지점 (갭 분석은 양방향이어야 공정하다)

| 축 | union-stack | 대상 문서 |
|---|---|---|
| 자동 기억 공고화 | [ADR-12]가 **증거로 기각**(자가생성 스킬 −1.8pp · 자동승격 안전 0/133 · LLM 생성 컨텍스트 −0.5~−2%에 비용 +20% · Cursor Memories 철회) | §9.3에서 Dream Worker를 **권장**. 효능 반대 증거 없음 |
| 반증 조건 사전 등록 | [ADR-15] — 시나리오 3개가 3-arm에서 전부 지면 층 폐기 | 없음. 어느 레이어도 폐기 조건이 없음 |
| 저장소 경계의 근거 | [ADR-11] — 누설 + 주입 경제 두 축 | §9.1에 이 축 자체가 없음 |
| 문서 신뢰 등급 | `tier: draft/reviewed/ratified`가 **산출물마다** [PRO-12] | E1/E2/D 등급이 **자기 문서에만** 적용 |
| 차단 정책 | 4값(REJECT만 차단 / CLARIFY·HOLD는 표면화) [PRO-11] | R0~R4는 세밀하나 결과는 3값 |
| 계측기 오염 | [ADR-07] — 자기 도메인 용어 레포의 문자열 매칭 계측은 자기언급에 오염(100%→0% 반전 실측) | 관측 함정 논의 없음 |

> 함의: 이 문서를 **로드맵으로 삼는 것은 틀린 사용법**이다([ADR-12] "생성 기계가 아니라 제거 기계").
> 문서 §9(메모리)를 채택 검토할 때 [ADR-12]가 이긴다.

## 3. 진짜 공백 (범위 안 · 미기각 · 실행 가능)

### A. 결정 원장이 어떤 주입 경로에도 없다 ★최우선

실측:
- `scripts/upward-fetch.js`가 수집하는 것은 **PLAN/FLOW/CON/ARCH/MTG + LSN**뿐 — `archive_ledger`는 안 본다.
- 부트스트랩(AGENTS.md)은 `project/` + `profile/` + `HANDOFF`. `archive_ledger.md`는 `.union-stack/` 루트라 **미포함**.
- 원장을 읽는 스크립트는 `permission-guard`(append 무결성)·`health`(엔트리 수)·`query`(라우팅 목적지)뿐 —
  전부 **감시·라우팅이지 주입이 아니다**.

결과: ADR 17건의 내용이 다음 세션에 도달하는 유일한 경로가 **HANDOFF §4의 손으로 적은 "재제안 금지" 목록**이다.
HANDOFF는 latest-only이고 매 세션 덮어쓴다 → 한 세션이 그 4줄을 빠뜨리면
[ADR-08](훅 재제안 금지)·[ADR-12](귀납 금지)·[ADR-15](반증 조건)가 **조용히 사라진다.**

대상 문서 §6.4가 정확히 이 문제를 지목한다 — *"거부 기록의 보존 — 무한 반복 차단"*.
이 레포는 그 규율을 **가장 잘 실천하면서 가장 취약한 방식으로 배송**하고 있다.

컨텍스트 예산(현재 2044/4000)이 원장 전문 주입을 막는 건 맞다. 필요한 것은 전문이 아니라 **필드**다.

### B. 유효기간 축(valid_time)이 ADR에 없다

- LSN은 **부분적으로 있다** — `health.js`의 `lessons lifecycle`이 `조건부(valid_reason)`를 센다([PRO-11] "LSN 수명 표면화").
- ADR·HISTORY는 **날짜(transaction_time)만** 있다. [ADR-08]은 "재검토는 마찰 비용 구조가 바뀔 때"라고
  유효 조건을 **산문으로** 적었고 기계는 읽지 못한다.
- → A의 `reopen_when:` 필드가 이 공백도 같이 닫는다. **A와 B는 한 조치다.**

### C. 효과 표면이 평면 밖 비구조 allowlist로 통제된다

- 4계층 권한이 다스리는 것은 `.union-stack/**.md` 쓰기뿐.
- 실제 비가역 외부 효과는 `.claude/settings.local.json`의 문자열 prefix 목록 ~100줄이 다스린다
  (`Bash(git push *)`, `Bash(git commit -m ' *)` 등). 문서 등급표로 `git push`는 R3.
- 이 레포에서 유일하게 **등급·근거 기록·게이트가 전부 없는** 통제면.
- [ADR-08]의 논리는 "훅으로 *강제*하지 않는다"였지 "효과 표면을 *관측*하지 않는다"가 아니다.
- → 레포 문법에 맞는 최소 조치는 새 게이트가 아니라 **`health.js` 관측 차원 1개**. 증거 후 판단.

### 낮은 우선순위
- 실행 예산(깊이/폭/반복 상한)이 [PRO-06] 플릿 규범에 없다 — 파티션 키만 있고 폭 상한이 없다.
- 문서 §10.2의 4~6층(SAST/SCA/secret/SBOM) 부재 — 단 zero-dep이라 SCA 표면 ≈0, 실질 공백 작음.
