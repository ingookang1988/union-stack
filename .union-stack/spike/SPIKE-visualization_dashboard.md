# SPIKE: 시각화 대시보드 — 만들 것인가

- 일자: 2026-08-18
- 진입점: HANDOFF §3 (후보 ①계보 트리 ②커버리지 히트맵 ③끊어진 참조 그래프)
- 방법: 후보 셋을 **수요**와 **가능성** 두 축으로 각각 친다. 가능성은 프로토타입 1벌로,
  수요는 "지금 관측되는 통증이 있는가"로 판정한다. 프로토타입은 스크래치패드에만 두고 커밋하지 않았다.

## 1. 판정 기준 (핸드오프가 미리 못 박은 것)
`scripts/fetch-eval.js`의 **101노드 적대적 합성 평면**을 가정 없이 렌더하는가. 이 평면의 레코드는
`{domain,id,file}` 뿐이라 **`status`·`tier`가 아예 없고 도메인도 5종**이다 — 실평면(13종, status 있음)을
가정한 렌더러는 여기서 깨진다. 즉 이 평면이 "어답터 레포를 모른다"를 대신 검사한다.

## 2. 가능성 — 통과
계보 트리 프로토타입(~70줄, zero-dep, `zfs_index.buildIndex` + `zfs_util.ancestorChain` 소비, 새 계산 0):

| 평면 | 문서 | 계보 노드 | 도메인 | 결과 |
|---|---|---|---|---|
| 실평면 | 54 | 28 | 13 | 렌더 OK |
| 적대 합성 | 101 | 66 | 5 | 렌더 OK (`status` 부재를 무가정 처리) |

색은 도메인 문자열 해시 → 색상환이라 **도메인 목록을 모른 채** 칠해진다. 하드코딩 0 제약 충족.

## 3. 발견 ① — 후보 ③은 시각화 문제가 아니라 **계측 결함**이다
"`ref integrity` 80(현재 112)건이 평평해서 아무도 안 본다"가 후보 ③의 근거였다. 해부하면:

| 부류 | 건수 | 성질 |
|---|---|---|
| `ADR-*` | 64 | **구조적으로 해소 불가** — ADR은 `archive_ledger.md`의 *행*이지 ZFS 파일이 아니다 |
| `GRANT-*` | 2 | 동일 — `GRANTS.md`의 행 |
| 외래 정본(`AXIOM`·`GRAM`·`MECH`·`ONTL`·`META`·`PRIN`) | 23 | 미커밋 위탁 스파이크 1개 파일에서만 발생 |
| 실제 조치 가능(`PLAN`·`LSN`·`EVD`·`WO`·`FLOW`·`PRO`) | 23 | 진짜 forward-ref 또는 오타 |

즉 **57%가 영원히 못 풀리는 참조**다. 목록이 안 읽히는 원인은 렌더가 아니라 신호대잡음비다.
그림을 그려도 잡음을 예쁘게 그릴 뿐이다. → **후보 ③은 만들지 않는다.** 대신 상류를 고친다
(원장 행 유래 ID를 `zfs_index`가 알게 하거나, 그 부류를 계수에서 분리).

## 4. 발견 ② — 계수 도메인이 계보 ID 공간을 오염시킨다
트리 첫 렌더가 즉시 드러낸 것:

```
01  PLAN ARCH INF CON DOM TOOL PHASE PRO    ← 서로 무관한 8개 문서가 한 노드
10  TOOL PRO                                 └ WO-10a-1
```
`TOOL-*`·`PRO-*`는 **일련번호**이고 `PLAN-*`·`FLOW-*`는 **계보 ID**인데, 구현은 둘을 한 ID 공간으로 본다.
실측: `node scripts/blast-radius.js TOOL-10` 과 `PRO-10` 은 **같은 영향권 3노드**를 낸다.
`ARCH-00`은 이 점에 대해 **침묵**한다(같은 id 다른 도메인이 같은 계보인 것은 의도 — `CON-01a`가 그 예다.
의도되지 않은 것은 *계수*가 그 공간에 섞이는 것이다).

**지금 해로운가:** 잠금 오탐 위험이다. 계수 도메인 문서 하나가 `Verifying`이면 무관한 문서의 편집이 막힌다.
현재 `Verifying` 0이라 실피해는 없다. **결정 필요 항목**이며 이 스파이크의 권한 밖이다.

## 5. 수요 — 후보별 판정
- **① 계보 트리: 만든다(범위 축소).** 근거는 취향이 아니라 실측이다 — 첫 렌더가 CLI 23세션이
  못 드러낸 구조 사실(§4)을 즉시 냈다. 값은 "큰/낯선 평면에서의 방향 잡기"이고 그게 어답터 운영자의 처지다.
- **② 커버리지 히트맵: 보류.** 실평면의 `PLAN`이 1개(그나마 예시)라 지금 그리면 빈 격자다.
  재개 조건: 어답터 실평면에서 `PLAN` ≥ 5.
- **③ 참조 그래프: 만들지 않는다.** §3.

남기는 미결:

- (b) §3 상류 수정 — `ADR`·`GRANT` 참조를 `ref integrity` 계수에서 분리.
