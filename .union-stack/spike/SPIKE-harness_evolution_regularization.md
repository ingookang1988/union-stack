# SPIKE: 하네스 진화의 정규화 — PRO 초안 근거

- 일자: 2026-10-08
- 계기: RRSI(arXiv 2609.24972v3, Google Cloud AI Research 외) 리뷰 → 인접 문헌 검색
- 목적: **루프 도입이 아니라** 개별 원리 중 이 평면에 이식할 것을 가려 PRO 초안의 근거로 쓴다
- 전제: [ADR-12] 자동 증류·자동 승격 루프는 차단 상태이며, 이 노트는 그 재개를 제안하지 않는다(§5)

---

## 1. 판정 기준 — 같은 층이 아니다

문헌의 하네스 진화는 **수백 과제 evolve set + 자동 제안자 + 수치 선택기**다.
이 평면은 **인간 승인 PRO 1건씩 + 소표본 A/B(E6: 실결함 5건, 팔당 5런, [ADR-16]·[ADR-17])**다.
따라서 이식 단위는 "루프"가 아니라 **선택 규칙(무엇이 영구 상태가 될 자격이 있나)**이다.
제안 측 장치(편집 예산 감쇠·구조적 탐색)는 인간이 PRO를 한 건씩 승인하는 순간 이미 충족된다.

## 3. 정독 리뷰 (작성 중 — 서브에이전트 결과 반영 예정)
### 3.1 Rethinking (2607.12227v1, Ai2·UW) ✅ HTML판 정독 (PDF 대조 미실시)
- 설정: Terminal-Bench 2.1(89과제), Opus 4.6·GPT-5.4·GPT-5.4 mini, 2회 평균, K=5·m=1 동예산. 진화 구현은 AHE(explore agent off) 1종.
- **X1 확정**: 탐색/시험 분리(45/10/34) 시 Harness Evolution 68.3 vs 직접 샘플링 67.7 (+0.6, 표 3, 2모델 평균). 34과제라 1과제≈2.9pp → +0.6은 과제 1개 미만.
- 무피드백 표 1: 진화 67.4 < 직접 샘플링 68.2 < 병렬 샘플링 72.3. **단순히 더 돌리기(병렬 샘플링)가 진화를 이김.**
- 진화된 수정은 과제별 패치·우회 누적 → "전략 증류가 아니라 수정 암기", 컨텍스트 비대(§5). R5·R6과 같은 병리.
- 권고: ①동예산 test-time scaling 대조군 필수 ②최적화 피드백과 최종 측정 분리 ③pass@k 병기 ④하네스 민감·여유 있는 벤치 사용.
- 한계: 벤치 1개(포화·하네스 둔감, 저자 인정), 진화 구현 약화, 유의성 검정 없음.
- **이식**: 후보 E 확정 근거. 추가로 (a) 판정 과제는 제안 작성 시 비노출, (b) n이 작아 유의하지 않으면 "효과 없음"이 아니라 **"판정 불가"**로 기록, (c) 런 25개는 과제 군집이므로 과제 단위 효과 병기, (d) 기준선이 천장·바닥인 과제는 신호 없음 → 스위트 구성 기준.
### 3.2 Bad Genius / CHASE (2609.18366v3, UCAS·NUS·CASIA) ✅ HTML판 정독 (원표 행 대조·절제 실험 미확인)
- **핵심 주장**: 지름길에는 두 종류가 있다.
  - 과제 특이적 지름길(문항 ID 인식 등): holdout으로 잡힌다.
  - **벤치마크 전역 지름길**(프로토콜 상관, 예: OfficeQA 단위 문장 다음 줄이 95.2%로 표): held-out 과제에도 같은 상관이 남아 **holdout으로는 잡을 수 없다**.
- 방법: Challenger가 의미·정답·채점을 보존하는 변환(식별자·레이아웃·도구 스키마·순서)을 제안한다.
  - **유효성은 LLM이 아니라 결정론적 Boolean 검사 7개**가 판정한다.
  - 새 표본에서 **확인**을 통과한 변환만 아카이브에 넣는다.
  - 아카이브는 이후 모든 후보의 회귀 제약이 된다. H0는 항상 합격 가능하다.
- 수치(OfficeQA 표 1): HarnessEvolve가 공개 점수 최고(69.30)지만 OOD ProV2는 최저(24.07). CHASE는 ProV2 30.37로 최고.
  - Syn-Ledger에서 HarnessEvolve의 이득 +11.70 중 +8.65가 벤치 의존분(ΔBS)이었다.
- 확인 단계가 위양성을 거른 사례: 변환 하나가 disc 10.20% → conf 4.17%로 줄어 기각됐다. **1회 측정으로 영구 제약을 만들지 않는다.**
- 한계:
  - OfficeQA 차이 0.4~1.3pp(cert 76문항×3회)는 잡음 범위다.
  - Syn-Ledger는 저자가 지름길을 심어서 자기순환 위험이 있다.
  - 모델 1계열, T=3, 비용 약 2.4배.
- **RRSI 누설 심사와의 관계: 보완 관계.**
  - diff 심사는 싼 1차 필터다.
  - "단위 옆 표를 먼저 봐라" 같은 *그럴듯한 일반 규칙*은 diff 심사를 통과한다. 이런 규칙은 행동(반사실 실행)으로만 잡힌다.
- **이식**:
  - E6 스위트 5건 전체가 공유하는 특성(이 레포 파일 배치·명명·순수 함수 국소 결함, [ADR-17] 한계 명시)이 바로 전역 지름길 후보다.
  - 형상을 바꾼 사본에서 같은 게이트를 다시 돌리는 [TOOL-26] 어답터 팔이 이미 반사실 팔의 원형이다. 새 장치가 필요 없다.
  - 후보 F로 등재한다.
### 3.3 ACE (2510.04618v3, SambaNova·Stanford·Berkeley) ✅ HTML판 본문 정독 (부록 A.2 이후 미확인, 학회명 미확인)
- **컨텍스트 붕괴 실측**: AppWorld에서 Dynamic Cheatsheet이 step 60에 18,282 tok·66.7 → 다음 step 122 tok·57.1. **무적응 기준선 63.7보다 낮음.** 통짜 재작성 1회가 누적 지식을 지우고 아무것도 안 한 것보다 나빠진다.
- 방법: 컨텍스트 = ID·helpful/harmful 카운터를 단 bullet 집합. Curator는 delta 항목만 내고 **병합은 LLM이 아닌 결정적 로직**. 중복 제거는 임베딩 유사도.
- 수치: AppWorld 평균 ReAct 42.4 → ACE 오프라인 59.4(GEPA 46.4). 금융 69.1 → 81.9. 적응 지연 −86.9%.
- 절제: Reflector가 최대 기여(제거 시 59.4→55.1).
- **해로운 조건**: GT 라벨도 신뢰할 실행 신호도 없으면 이득이 줄거나 뒤집힘(온라인 FiNER 무라벨 −3.4). 규칙 하나로 충분한 과제에서는 짧은 지시가 나음.
- **이식**:
  - 후보 D 확정 근거. AGENTS.md의 "extreme compression"을 **통짜 재작성 금지 + 항목 단위 병합/퇴출**로 한정해야 한다.
  - HANDOFF(매 세션 전체 재작성, latest-only)가 붕괴 위험이 가장 큰 자리다. 재작성 후 필수 ID가 빠지거나 길이가 급감하는지 검사할 여지가 있다.
  - 교훈은 실행 신호에 묶인 것만 승격한다는 원칙은 [ADR-12]·[PRO-22]와 정합한다.

## 5. 하지 않을 것
- 자동 제안·자동 채택 루프 — [ADR-12] 재개 조건 미충족, 그리고 X1·R2가 일반화 실패를 보고한다.
- 편집 예산 감쇠·구조적 탐색 — 인간 승인 1건 단위에서 이미 충족(§1).
- 진화 결과 인용 시 기사 수치 사용 — 기사의 "토큰 감소"는 비교 기준(무정규화 진화)이 빠져 있고, H0 대비로는 증가(R9).
