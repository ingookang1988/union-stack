# feature/ — actual × state (the living product surface) guide
> **Grid:** actual (observed) × state. **Permission:** Wiki (agent atomic writes).
> **Change velocity:** frequent.

## Goes in: "what is alive." A map of currently-working product features.
##   `live.md` is the one manifest the template ships. Split it (e.g. a `target`/`hold` manifest)
##   only when the live map actually grows painful — don't pre-create empty files.
## flow/: E2E data-lineage records (FLOW-*) and per-feature test cases (tier 3) under the same ZFS ID.
##   Boundary with reference/contracts/ — **"what breaks when it changes?"** ([PRO-16]):
##   only the observation goes stale → here (Wiki). **Code on both sides breaks → CON-*, Schema,
##   approval required** — reference it by bracket ID instead of restating the payload shape here.
## Stays out: norms, planning, work. Only "the state that exists right now."
