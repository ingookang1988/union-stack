## 4. 미해결 / 주의
- **회전 주기가 짧다**: 항목당 ~2KB 라 [PRO-18]의 60%(18KB) 목표는 헤드룸 5건뿐(16.3 → **28KB**,
  다음 ADR 에 WARN). **두 번째 회전 때 60% 조정 여부를 판정**하라.
- **회전본의 누설 통과가 약하다**: 근거가 본문의 "예시" 6회다(MARKER 이월 항목) — 보호 표면 +1.
- **[LSN-17] 잔여 위험**: 팔이 env·data 두 축을 덮었지만 픽스처는 **상류가 지어낸 대안 형상**이다 —
  실데이터에서만 참인 사실은 여전히 하류 제보로 온다. 규율: **팔이 잡은 형상은 `dataShape()` 에
  추가**(픽스처가 곧 회귀 고정). 상태 축은 [ADR-36]① 한 사례만 덮였고 일반형은 무계측.
- **[LSN-17]의 배송 한계(미해결)**: 결함은 계보 없는 `scripts/*.js` 에 있는데 경고는 계보 17
  진입에만 뜬다([ADR-18] "보존 ≠ 배송"과 같은 자리 — 배송 경로 신설은 제안 감).
- **[TOOL-25] 카드 4KB 밀착**: 축이 늘면 축별 분할(`TOOL-25a`).
- **팔의 비용**: 사본 227파일 × 2축 + 스위트 1회. 축이 늘면 형상별 잡 분리를 판단할 것.
- **기존 어답터의 첫 `--apply` 는 `--force` 필요**(앵커 부재). `package.json` 은 review 라
  `npm test` 글롭화가 자동 전파되지 않는다.
- **미커밋 유지**: `ref/` 와 `spike/SPIKE-fdt_canon_import_utility_analysis.md`. 공개 여부는 인간 판단.

  목록 대조로 마스킹은 없앴지만 red 자체는 남는다. **로컬 red 를 "기존 것"으로 읽지 말 것.**
- **이월 2건**: ①`ARCH-00` 인용 게이트가 `leakage-guard` 하나뿐 → 어답터에서 무게이트
  ②누설 가드 판정이 약하다. **[WO-10a-1] 인간 대기**: E6 10런은 top-level 세션 필요.
- 재제안 금지 목록은 **AGENTS.md의 `blocks-index` 블록**이 소유한다 — 여기 복제하지 말 것([ADR-18]).

## 5. 검증 상태
- 수치는 frontmatter `verification:` 이 정본. 아래는 **판정이 아니라 방법**이다.
- **회전 성공 바는 집합으로 잰다**(수가 아니라) — `gather()` 가 *(파일, 참조)* 쌍을 파일별로 중복
  제거하므로 텍스트가 옮겨가면 수는 변한다. 미해소 ID **집합** 37종 불변이 판정이었다([ADR-36]).
- **가드는 양방향으로 확인한다**: 회전 커밋 통과 + 한 줄 뺀 상태 REJECT(소멸 항목 지목).
- **"렌더 본문 원문 마커 0"(dashboard.test)은 실평면 단언이고 약화 금지.** [ADR-30]이 없앤 것은
  *픽스처 하드코딩*, 이것은 *데이터 무관 불변식* — 후자는 실평면에 걸려야 값을 한다([ADR-37]).
- **어답터 모드**는 이제 `node scripts/adopter-arm.js` 하나로 잰다(CI 스텝과 같은 것).
- **배송 형상(CI)도 따로 돈다**: 사본에서 미커밋물을 지우고 전체 스위트 — 로컬 형상이 배송 형상과
  다르면 로컬 green/red 가 둘 다 거짓말이 된다([ADR-39] 가 그 실측). 푸시 전 필수.
