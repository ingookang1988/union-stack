# [WO-29a-7] 약화 판별 오탐 보정 — 상류 현재본과 같은 파일·상류 전용 사본 삭제 제외 — [PRO-29] ② 6회차

## 목표
[PRO-29] ② 상태(2026-10-19)의 정밀도 결함 1: census 6회차 신규 8 중 `weak:*` 5건이 전부 오탐이었다(파일 기준 6 — A 1 · C 5). 약화는 **어답터가 스스로 만든 변화**에서만 센다.
- **제외 1 — 상류 배송본**: diff 의 파일이 지금 **상류 현재본과 블롭이 같다** → 그 변화는 어답터가 `--apply` 로 받은 상류 변경이다(A·C `query.test.js` · C `leakage-guard.test.js`).
- **제외 2 — 상류 전용 사본 삭제**: 삭제된 파일이 상류 `ship-manifest.json` 의 upstreamOnly → 상류가 "지워도 된다"고 한 것을 지운 것(C `eval`·`fetch-eval`·`token-accounting` 테스트).
- 제외한 파일 수는 원자료에 남긴다(`excluded: {delivered, upstreamOnlyDeleted}`) — 조용히 빼지 않는다.

## 수용 기준
- 테스트 먼저([ADR-40]): 실 git 픽스처 — 상류본과 같은 테스트 변경 = 신호 0 · 어답터 자체 변경(상류와 다름) = 신호 유지 · 상류 전용 사본 삭제 = 0 · 어답터 자체 테스트 삭제 = 유지 · excluded 수 기록 · 상류 트리 없음 = 제외 없이 현행.
- 6회차 원자료 재계산(dry-run): weak:* 오탐 5 → 0 이어야 한다(남으면 그 사유를 증거에). 다른 이탈(sync·rule·gate)은 불변.
- 주입 실험 재실행 4/4 유지(주입한 테스트 삭제는 어답터 자체 파일 → 남아야 한다). 팔 7 형상 · 스위트 회귀 0 · 카드 [TOOL-30] · CHANGELOG.
