## 1. 전제 발견 — 세 PRO 모두에 선행하는 것 (설문 밖 · 3/3 또는 4/4)

1. **상류 ID 와 로컬 ID 가 같은 공간을 쓴다.** 어답터에서 `[PRO-25]` 는 로컬 문서다. C 의 strict 참조 린터는 상류 `[PRO-26]` 을 로컬 문서로
   **오해소**했고 `[PRO-24]` 에서 Fail-close 했다 — 설문 파일 자체가 걸렸다. PRO-24 ③(a) · PRO-25 ④ · PRO-26 ① 전부 영향.
   → **상류 ID 네임스페이스**(`[up:PRO-25]` 꼴 + 도구 인식) 없이는 어떤 환류도 안전하지 않다.
2. **상태 어휘가 enum 이 아니고, frontmatter 없는 문서가 많다.** A: WO 99/179 frontmatter 없음 · PRO 20/43 status 없음 · 종결 어휘 `Done`.
   B: PLAN 에 비enum 값 · 로컬 PRO 17/17 YAML 없음. C: status 38종 자유 문자열(커밋·승인 패킷·사람 발언 인용 포함).
   frontmatter 를 읽는 상류 도구는 평면의 절반을 못 본다. → `adapter.json statusMap` + **일회성 백필 스크립트**가 PRO-22/24/25/26 공통 선행.
3. **"계보 루트 = PLAN" 가정이 2/3 에서 거짓.** A: WO 루트 38 중 26 에 PLAN 없음(우산 WO 루트 · 잎 ID 루트), 레거시 번호대는
   **도메인별 독립 채번**(같은 숫자 = 다른 주제). C: 전역 일련번호라 ID 산술 루트 **0/438**, 계보는 frontmatter `plan:`(74%)·`parent:` 에만.
   → upward-fetch · PRO-26 · PRO-25 GC 전부 **frontmatter 관계를 1급 경로**로 인정해야 한다.
4. **동명 파일의 로컬 분기.** A: 상류와 동명인 하네스 스크립트 **14/14 diff**(최대 338줄). C: health·권한 가드·참조 린터·예산 계측 분기.
   B: sync 파일 7 개조. `localOwned`(글롭)로는 못 가른다. → **`localForked`** 범주(3-way 안내만, 자동 적용 금지).
5. **상류 도구 결함 2.** `health.js --root` 미구현(그리고 엉뚱한 대상을 측정하고 통과하는 것은 "0건 검사" 원칙의 재위반) ·
   `zfs-linter` ID 유일성 미검사.

### 2-2 임계 — 수렴
- Verifying 은 **수가 아니라 정체 일수**(4/4). A·B 에서 Verifying = "배포됨·실회차 대기" 라 10 은 평시값이거나 무음.
- 평면 지연은 **평면별 분리 + 가장 낡은 파일 기준**(4/4). 생성 뷰(state)는 "지연"이 아니라 "안 돌림"으로 별도.
- 증류 정체는 **비율이 아니라 증분**("마지막 LSN 이후 종결 N건"). LSN 은 파일 수가 아니라 **갱신 커밋·행**(B 는 행 추가로 키운다).
- 보관 부채·GC 는 어답터가 **끌 수 있어야**(C) 하고, 종결 어휘 매핑 없이는 0 으로 나온다(A).
- 발행 증분: 20(A) · 30(B) · 40 또는 30일(C) — 출하 주기에 비례. 기본값 30, adapter 로 덮어쓰기.

## 4. [PRO-24] 어답터 연결

  블랙리스트는 100개를 적어야 한다) + 글롭 충돌 시 우선순위(B: `*-linter.js` 가 상류 린터와 겹침).
- 배송 범주 — 받지 않을 것(3/3 일치): eval · eval-arm · fetch-eval · scenario-rubric · token-accounting · hook-replay · check-prereqs · adopter-arm ·
  e6-workspace; 조건부: leakage-guard(비공개) · dashboard · hooks.js/hook-*(로컬 가드가 있는 곳) · ci.js/ledger.js(등가물이 있는 곳).
  받고 싶은데 못 받은 것: health · work-close · template-update · transcript-stats · session-friction · ref-linter · lineage-tree · worktree ·
  handoff-linter · test-catalog(B 는 `--apply` 를 아무도 안 돌렸다).
- census — 구멍 3: health JSON `sizes` 에 파일명(제품명) · `upstream_candidate` 제목이 제품 정보 → **ID 만** · C 의 status 문자열은 커밋·승인 패킷·
  사람 발언을 담는다 → **첫 토큰만**. `evidence:` 는 별칭 맵 없이 C 에서 0/438 오보. 로컬 도메인은 INFO. census 는 어답터에 **파일을 쓰지 않는다**(A).
